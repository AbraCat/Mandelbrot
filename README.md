В даннной работе исследются методы оптимизации вычисления множества Мандельброта.

Создано графическое приложение на Qt, позволяющее просматривать множество. С помощбю стрелок можно перемещаться, с помощью клавиш Z/X - увеличивать/уменьшать масштаб.

Главным узким местом программы является функция, вычисляющая множество, а именно внутренний цикл. Создано несколько версий функции с разными оптимизациями. 

* Наивная версия (calc_set_unopt). Вычисляет каждую точку в отдельной итерации цикла. Оптимизации отутсвуют.
* Развертывание цикла (calc_set_unr). В каждой итерации производятся вычисления сразу для 8 точек с использованием массивов из 8 элеметов типа float. Именно столько чисел помещается в ymm-регистры. Операции, производящиеся над массивами, соответствуют AVX инструкциям x86-64 для ymm-регитсров.
* Intrinsic функции (calc_set_intr). За итерацию обрабатываются 8 точек, но теперь используются intrinsic-функции из заголовочного файла immintrin.h, компилирующиеся непосредственно в AVX интрукции.

Было измерено время работы этих функций с двумя разными компиляторами. Результаты приведены в таблице ниже. Программа компилировалась с флагом -O2. Время измерено в миллисекундах. В последнем столбце приведено среднее время для тестов, отклоняющихся не более чем на $3\sigma$, где $\sigma$ - стандартное отклонение.

| Компилятор | Флаги         | Функция     | Кол-во тестов | Среднее время | Станд. отклонение | Средн. время хороших тестов |
| --------   | ------------- | ----------- | ------------- | ------------- | ----------------- | --------------------------- |
| g++        | -mavx2        | unoptimized | 256           | 123.7         | 4.1               | 123.4                       |
| g++        | -mavx2        | unrolled    | 256           | 19.2          | 0.8               | 19.2                        |
| g++        | -mavx2        | intrinsic   | 256           | 19.1          | 0.8               | 19.1                        |
| clang      | -mavx2        | unoptimized | 256           | 126.8         | 4.1               | 126.6                       |
| clang      | -mavx2        | unrolled    | 256           | 28.3          | 1.7               | 28.1                        |
| clang      | -mavx2        | intrinsic   | 256           | 21.3          | 1.2               | 21.1                        |

Мы видим, что первая оптимизация дала прирост производительности в несколько раз. Вторая же дала прирост только при компиляции clang-ом, при компиляции gcc скорость не изменилась. Можно сделать вывод, что gcc сразу увидел соответствие циклов AVX инструкциям, и сгенерировал примерно одинаковый код при развертывании циклов и использовании intrinsic-ов. Также можно заметить, что код, сгенерированный gcc, быстрее, чем clang.
