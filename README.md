В даннной работе исследются методы оптимизации вычисления множества Мандельброта.

Создано графическое приложение на Qt, позволяющее просматривать множество. С помощбю стрелок можно перемещаться, с помощью клавиш Z/X - увеличивать/уменьшать масштаб.

Главным узким местом программы является функция, вычисляющая множество, а именно внутренний цикл. Создано несколько версий функции с разными оптимизациями. 

* Наивная версия (calc_set_unopt). Вычисляет каждую точку в отдельной итерации цикла. Оптимизации отутсвуют.
* Развертывание цикла (calc_set_unr). В каждой итерации производятся вычисления сразу для 8 точек с использованием массивов из 8 элеметов типа float. Именно столько чисел помещается в ymm-регистры. Операции, производящиеся над массивами, соответствуют AVX инструкциям x86-64 для ymm-регитсров.
* Intrinsic functions (calc_set_intr). За итерацию обрабатываются 8 точек, но теперь используются intrinsic-функции из заголовочного файла immintrin.h, компилирующиеся непосредственно в AVX интрукции.

Было измерено время работы этих функций с двумя разными компиляторами. Результаты приведены в таблице ниже. Программа компилировалась с флагами -O2 -march=native. Время измерено в миллисекундах. В последнем столбце приведено среднее время для тестов, отклоняющихся не более чем на $3\sigma$, где $\sigma$ - стандартное отклонение.

| Компилятор | Функция     | Кол-во тестов | Среднее время | Станд. отклонение | Средн. время хороших тестов |
| --------   | ----------- | ------------- | ------------- | ----------------- | --------------------------- |
| g++        | unoptimized | 256           | 100.4         | 4.0               | 100.1                       |
| g++        | unrolled    | 256           | 26.1          | 1.5               | 26.0                        |
| g++        | intrinsic   | 256           | 19.7          | 1.3               | 19.5                        |
| clang      | unoptimized | 256           | 98.5          | 3.2               | 98.3                        |
| clang      | unrolled    | 256           | 28.4          | 1.6               | 28.2                        |
| clang      | intrinsic   | 256           | 21.0          | 1.2               | 20.9                        |

Как мы видим, первая оптимизация дала прирост производительности примерно в 4 раза. Компилятор догадался, что операции над 8 точками независимы друг от друга и создал код, выполняющийся параллельно за счёт параллелизма на уровне инструкций.

Вторая оптимизация дала прирост производительности примерно в 1.3 раза по сравнению с первой. Теперь операции над числами выполняются параллельно с помощью AVX инструкций.
